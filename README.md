# Smart Health Monitoring System 🩺

## Overview
A simple IoT-inspired project that simulates health monitoring using Python, Flask, and basic ML logic.  
It collects simulated sensor data (heart rate, oxygen level, temperature) and analyzes it for anomalies.

## Features
- Real-time health data simulation
- Basic anomaly detection
- REST API endpoint (`/health`) for data + analysis

pip install -r requirements.txt
python app.py
